# Language Governance and Human Evidence

## HUMAN-GOVERNANCE-001

Every language-affecting change must include a numbered proposal, normative
specification, rule or inventory update, test or conformance evidence,
compatibility evidence, traceability evidence, and documentation or examples.
Repository-wide validation must also prove that rule inventory IDs,
specification paths, and evidence paths resolve.

The current proposal template contains every item in the constitution's
mandatory feature contract. CI runs governance validation before compilation
and assurance.

Readability and comprehension claims require real anonymized participant
evidence collected under the versioned protocol. Synthetic records may test the
analysis implementation but must never be published as participant findings.
Stable graduation additionally requires an independent security and
specification review with recorded methodology, findings, remediation, retest,
residual risk, and explicit recommendation.
